# brain-grill：逼问式澄清（grilling 变体 + 代码事实核查）

参考 grilling 的机制，加两条硬纪律。适用：brain-roadmap 建立/调整、brain-decision（强制前置）、brain-plan（取舍未决时），也可被用户单独调用。

## 机制（沿用 grilling）

把议题映射为**设计树**：每个决策分叉出挂在它下面的子决策。按**轮次**推进：每轮只问 frontier 上的问题——即前置已定、现在就能问且不必猜后续答案的问题；一次性问完整轮，每题编号并给出推荐答案（`➡️`），然后停下等用户回答。用户的回答重塑决策树：已定的节点解锁此前被阻塞的问题，重算 frontier 进入下一轮。本轮答不了、依赖本轮其他问题的，留给后续轮次。frontier 清空（树的每个分支都走完、没有遗留假设）即结束。

## 硬纪律

1. **事实自查，不问用户**：能从环境查到的（代码、文件、数据）绝不问用户；事实源限定 codegraph_explore（可用时优先）或当场实测，**不假设、不凭记忆**。探查未完成不阻塞其他 frontier 问题，只阻塞依赖探查结果的下游问题。
2. **决策归用户**：每个真正的决策摆到用户面前，等回答，不代拍板。
3. **无假设收尾**：结束时输出「已确认共识清单」——编号列出所有已定结论（决策 + 依据事实的引用），作为 brain-roadmap / brain-decision / brain-plan 的直接输入素材。清单本身需用户确认。
