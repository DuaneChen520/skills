# brain-verify：完工核查

规则权威：`brain/rules.md`。核查对象：`brain/plans/plans-<时间戳>.md`。本技能只做**事实核查**，不做需求澄清——不通过且源于需求模糊时，建议回 brain-decision / brain-plan 修正。

## 步骤

1. 读目标 plans 文档的「方案」与「验收标准」。
2. **逐项核查验收标准**：用 codegraph_explore 复核实际代码变更是否与计划一致（可用时优先图谱；图谱未覆盖当场实测——读文件、跑命令）。不凭 git log、会话记忆或"看起来改了"下结论。
3. 核查每个变更是否超出计划范围（未计划的改动列出）。
4. 结论写回 plans 文档：
   - 验收清单逐项勾选；
   - 文末追加「核查记录」（日期 + 通过/不通过 + 偏离项与证据：文件路径·行号）。
5. 展示核查结论，等用户确认：
   - 通过 → 建议运行 brain-archive 归档；
   - 不通过 → 列明原因，建议修复后重跑本技能，或回 brain-plan 修订计划。
